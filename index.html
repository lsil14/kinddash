Esta URL acima é a que deve estar cadastrada no Azure em:
Microsoft Entra ID → App registrations → Seu Aplicativo → Autenticação → Aplicativo de página única (SPA).

Passo a passo no Azure Portal para resolver AADSTS500113:

  1. Acesse portal.azure.com e abra seu aplicativo em App registrations.
  2. No menu lateral esquerdo, clique em Autenticação (Authentication).
  3. Em Plataformas, certifique-se de que existe a plataforma SPA (Single-page application). Se não existir, clique em Adicionar plataforma → Aplicativo de página única.
  4. Cole a URL acima no campo de URIs de redirecionamento e clique em Salvar no topo da página.
